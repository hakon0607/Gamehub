- Nytt: Bakgrunnsbilder under Innstillinger → Utseende. Velg eget bilde (JPG, PNG, WebP, BMP) til skrivebordet og til låseskjermen, med forhåndsvisning, filnavn og oppløsning. Bytt, fjern, gå tilbake til Windows-standard, eller bruk samme bilde på begge. Har du flere skjermer kan hver skjerm få sitt eget bilde.
- Skrivebordet settes gjennom Windows sitt eget IDesktopWallpaper-grensesnitt (samme som Innstillinger-appen bruker). Låseskjermen settes gjennom Windows sitt LockScreen-API for brukeren som er logget inn – Windows gir ingen måte å lese det tilbake, så kortet viser det GameHub sist sendte. En jobb-/skolepolicy kan blokkere låseskjermen; da sier GameHub hvorfor.
